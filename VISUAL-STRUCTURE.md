## Legend

- 🎥 = Video background
- 📷 = Photo background
- [VIDEO BACKGROUND] = Full-screen video with overlay
- GLASS = Glass morphism card effect (blur + transparency)
- [Button] = CTA button
- ▶ = Expandable FAQ item

## Color Coding

- **Video sections** = 3 sections (Hero, Why Onevia, How It Works)
- **Glass cards** = Used throughout for modern UI
- **Photo backgrounds** = Testimonials only
- **Standard sections** = Locations, Savings, Services, FAQ

## User Journey Flow

```
ENTER → Hero (Get Started)
       ↓
     Why Onevia (Learn benefits)
       ↓
     How It Works (Understand process)
       ↓
     Locations (Choose clinic) ← ALL CTAs LEAD HERE
       ↓
     Services (Explore offerings)
       ↓
     Savings (See value)
       ↓
     Testimonials (Build trust)
       ↓
     FAQ (Answer questions)
       ↓
     Final CTA (Take action) → LOCATIONS PAGE
```

## Key Design Principles

1. **Video First** - Top 3 sections use video for engagement
2. **Glass Throughout** - Consistent glass morphism aesthetic
3. **Clear Hierarchy** - Logical flow from awareness to action
4. **Single CTA** - All paths lead to location selection
5. **Social Proof** - Testimonials positioned after value prop
6. **Remove Friction** - FAQ before final CTA

## Responsive Behavior

**Desktop (1024px+)**
- 3-column testimonials
- 2-column benefits grid
- 4-column services grid

**Tablet (768-1023px)**
- 2-column testimonials
- 2-column benefits grid
- 2-column services grid

**Mobile (<768px)**
- 1-column everything
- Stacked layouts
- Full-width cards
- Larger touch targets
